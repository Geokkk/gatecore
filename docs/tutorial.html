gatecore 新手部署教程

从一台空服务器开始，一步一步装出完整形态：Reality 直连入口 + Argo 备用入口 + 域名面板 + 家宽出口。全程约 20 分钟。

先说清这套东西是什么。它由三段组成：入口（Xray，负责让你的手机连进来）、出口核心（gatecore，负责选家宽节点、建 OpenVPN 隧道）、家宽节点（VPN Gate 志愿者家里的宽带，你的最终出口 IP 就是它）。链路长这样：
手机 → 入口 → gatecore 网关 → OpenVPN 隧道 → 家宽节点 → 互联网。
下面的步骤就是把这三段依次接起来。文中 example.com 是占位示例，操作时换成你自己的域名。

0准备清单

先把这四样备齐，后面每一步都顺。

  • 一台云服务器：Ubuntu 22.04，能用 root 或 sudo 登录（免费小机型就够）。
  • 一个域名，且 DNS 已托管到 Cloudflare（Argo 备用入口和面板要用它）。解析分两处：Argo 子域名的解析由隧道自动生成，不用你手动加；面板子域名要你自己加一条 A 记录，指到服务器 IP、选灰云（仅 DNS）——证书签发不需要它，但面板网址能不能打开靠它，第 4 步装面板之前先加好。
  • 一个 Cloudflare 账号（就是上面那个域名的账号）。
  • 手机客户端：Android 用 v2rayNG；iPhone 用 Streisand 或 Shadowrocket。
  • 一个 SSH 客户端：电脑上能连服务器终端就行（Windows 可用 Netcatty、PuTTY 等）。

1先放行防火墙（装之前做）

端口不通，后面装得再对也连不上。这一步在部署之前先做完。

  1. 云厂商控制台里找到这台服务器的安全组 / 防火墙，放行 TCP 端口：443（入口）、8443（面板）。如果你的云安全组默认全放行，这条可跳过。
  2. 如果服务器本机 iptables 末尾有一条 REJECT 规则（不少免费机的默认镜像有），在 SSH 里执行下面三条，把放行插到 REJECT 前面：
sudo iptables -I INPUT -p tcp --dport 443 -j ACCEPT
sudo iptables -I INPUT -p tcp --dport 8443 -j ACCEPT
sudo iptables -I INPUT -p tcp --dport 80 -j ACCEPT

（80 是给证书签发留的通道，一并放行最省事。22 是 SSH 端口，你能连上就说明它本来就是通的，不用动。）

💡 这三条只保存在内存里，服务器重启后会丢：装一次持久化工具保存下来（sudo apt-get install -y iptables-persistent，安装时选 Yes 保存当前规则），或每次重启后按上面命令复查一遍。

2建一个 Cloudflare API 令牌

第 4 步给面板签 https 证书时要用。提前建好，到时候直接粘贴。

  1. 登录 Cloudflare 控制台，点右上角头像 → 我的个人资料 → API 令牌 → 创建令牌 → 选创建自定义令牌。
  2. 权限加两条：
    类别项目级别
    区域DNS编辑
    区域区域读取
  3. 「区域资源」选你的那个域名，然后创建。
  4. 把生成的令牌复制保存到一个顺手的地方（它只完整显示这一次）。

3在 Cloudflare 建一条隧道

Argo 备用入口要借这条隧道进来。这一步先把隧道建好并连上服务器。

  1. 进入 Cloudflare Zero Trust 控制台 → 网络 → 隧道 → 创建隧道，类型选 Cloudflared，给它起个名字（任意）。
  2. 它会显示一条安装命令（形如 cloudflared service install xxxx 或带 token 的运行命令）。把这条命令复制到服务器的 SSH 里执行。
  3. 回到隧道页面，状态变成健康 / 已连接，这一步就完成了。公共主机名先不用加，第 4 步装到 Argo 时再回来加一条。

4一行部署，跟着向导走四步

SSH 登录服务器，执行这一条命令，之后全部是向导问答：回车 = 接受默认。

git clone https://github.com/Geokkk/gatecore.git && cd gatecore && sudo bash deploy.sh
  1. 先装本体：向导会自动先装好 gatecore 核心，并打印网关和面板的账号、密码。
📌 把这屏打印的账号密码截图保存。忘了也没关系：装完后在服务器输 gk 选 9，随时能再看面板地址和密码。
  1. 选入口：出现四个选项时输 1（Reality 路线，免域名免证书；直接回车也是 1）。装完会打印一条 vless:// 开头的链接——这是手机直连链接，先复制保存。Reality 的伪装域名（SNI）脚本已自动配好、用的是大站域名，保持默认，不要改成你自己的域名。
  2. 加装 Argo 备用入口：问「加装 Argo?」时直接回车。它让你输入 Argo 域名，填一个子域名，例如 argo.example.com（换成你自己的域名）；再问「优选域名」时直接回车用默认（cf.090227.xyz，第三方的、可能过期失效；不通时切回原版链接）。后端装好后，按屏幕上的提示回到第 3 步那条隧道的页面：公共主机名 → 添加：子域填 argo、域名选你的域名、服务类型选 HTTP、URL 填 localhost:31301，保存。约一分钟生效。脚本最后打印两条 Argo 链接（原版和优选版），都复制保存。
  3. 准备域名证书：问「准备域名证书?」时直接回车；再问证书方式时选 2（CF DNS 验证，不用开 80 端口验证，最省事）。
  4. 面板挂域名：问「把面板挂到域名?」时直接回车。输入面板域名，例如 panel.example.com（换成你自己的）；它让你粘贴 Cloudflare 令牌时，把第 2 步建的令牌粘进去（粘贴时屏幕不显示字符，是正常的，粘完回车）。装完会打印面板网址（形如 https://panel.example.com:8443/一串随机字符/）和账号密码，一并保存。
✅ 向导四步走完，服务器这一侧就齐了。接下来先去连节点，再回手机导入链接——顺序别反：没连节点之前，手机链接测不通是正常的，因为链路最后一段还没接上。

5连上一个家宽节点

这一步把链路最后一段接上。

  1. SSH 登录服务器，输入 gk 回车，打开交互面板。
  2. 选 4（连接节点），国家代码直接回车（默认 JP 日本）。它会先探测一批候选节点，再自动连上最合适的一个。
  3. 看到状态行显示当前出口 IP（和国家代码），就是连上了。
  4. 想再确认一次：选 6（出口自检），返回的 IP 与国家和所选节点一致即可。
💡 以后日常操作都在 gk 里：换节点选 4，看客户端链接选 8，看面板地址选 9，重启服务选 10，升级/卸载选 11。不用记任何命令。

6手机导入链接

  1. 复制第 4 步保存的 Reality 链接，打开 v2rayNG，点右上角 + → 从剪贴板导入。
  2. 点中刚导入的这条配置（让它成为当前选中），然后点右下角的真连接测试（或在配置上长按测速）。显示一个毫秒数字 = 通了。
  3. 把两条 Argo 链接也用同样方法导入，留作备用；各测一次真连接，能显示延迟即可。
  4. 判读规则就一条：显示 -1 时，先回服务器 gk 选 1 看是不是还没连上节点；已经连着的话，实际打开浏览器上网试，以真实使用为准。

7打开面板，选个运行模式

  1. 浏览器打开第 4 步打印的面板网址，用打印的账号密码登录。
  2. 面板里能看当前出口、按国家浏览节点、点一下就切换。下面是四种运行模式，选一个保存：
模式行为适合
手动只用你选的节点；它断了不会自动切，等你自己在面板或 gk 里重连想自己掌控
自动程序按质量自动选节点、自动切换新手推荐，省心
固定国家只在你指定的国家里自动选需要固定地区
固定 IP只认当前这一个节点；它下线就暂时断网，它恢复后自动回来需要固定出口 IP

8验收清单

五项全勾，完整部署就完成了。

  • □ gk 选 1：状态显示已连接，有当前出口 IP
  • □ gk 选 6：出口自检的 IP / 国家与所选节点一致
  • □ 手机 Reality 链接：真连接测试显示延迟数字
  • □ 手机 Argo 链接：真连接测试显示延迟数字
  • □ 浏览器能打开面板网址并成功登录
